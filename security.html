IPv6 Protocol Manager

Disable IPv6 protocol to enhance privacy and reduce attack surface. IPv6 can leak your real location even when using VPN.

🐧 Linux Script 🪟 Windows PowerShell

Why disable IPv6?

  • Prevents IPv6 DNS leaks when using VPN
  • Reduces network attack surface
  • Eliminates IPv6 transition tunneling
  • Blocks IPv6-based tracking methods

Geolocation Service Manager

Disable system-level geolocation services to prevent location tracking by applications and services.

🐧 Linux Script 🪟 Windows PowerShell

What gets disabled:

  • Windows Location Service (lfsvc)
  • System location consent settings
  • Location sensors and APIs
  • Geoclue service (Linux)
  • GNOME location services

Privacy Tools Usage:

1 Download the appropriate script for your OS
2 Run as administrator/root with elevated privileges
3 Follow the interactive menu to disable services
4 Restart your system for full effect

Security Best Practices

  • Use strong, unique passwords for all accounts
  • Enable two-factor authentication (2FA)
  • Keep software and systems updated
  • Use secure networks and VPN when necessary
  • Be cautious with email attachments and links
  • Regularly review privacy settings
  • Maintain regular backups of important data
  • Monitor accounts for suspicious activity
