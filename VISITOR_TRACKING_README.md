## 🚀 Installation & Setup

### 1. File Permissions
```bash
# Make data directory writable
chmod 755 data/
chmod 666 data/visitors.json
chmod 666 data/daily_stats.json

# Make API directory executable
chmod 755 api/
chmod 644 api/*.php
```

### 2. Web Server Configuration

#### Apache (.htaccess)
Create/update `.htaccess` in root directory:
```apache
# Enable PHP
AddType application/x-httpd-php .php

# Allow API access
<Directory "api">
    Options -Indexes
    AllowOverride None
    Require all granted
</Directory>

# Protect data directory
<Directory "data">
    Options -Indexes
    AllowOverride None
    Require all denied
</Directory>

# Custom error pages
ErrorDocument 403 /blocked.html
```

#### Nginx
Add to nginx configuration:
```nginx
location /api/ {
    try_files $uri $uri/ =404;
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.0-fpm.sock;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}

location /data/ {
    deny all;
    return 403;
}
```

### 3. PHP Requirements
- PHP 7.4 or higher
- JSON extension (usually included)
- File write permissions for `/data/` directory

### 4. Integration

#### Basic Integration (Auto-enabled)
The tracking system automatically starts when pages load. No additional setup needed.

#### Manual Integration
Add to any HTML page:
```html
<link rel="stylesheet" href="assets/css/visitor-tracker.css">
<script src="assets/js/visitor-tracker.js"></script>
```

#### Custom Configuration
```javascript
// Manual initialization with custom options
window.xxmxliTracker = new VisitorTracker({
    showInfo: true,        // Show visitor info card
    debug: true,           // Console logging
    autoBlock: true,       // Auto-redirect blocked IPs
    apiEndpoint: '/api/visitor-logger.php'
});
window.xxmxliTracker.init();
```

# Check log file sizes
ls -lh data/

cp data/visitors.json data/visitors_backup_$(date +%Y%m%d).json

- Only essential data is tracked to minimize overhead
- Background processing doesn't block page loading
- Caching for repeated IP lookups

## 🔧 Troubleshooting

### Common Issues

#### Tracking Not Working
1. Check PHP errors: `tail -f /var/log/apache2/error.log`
2. Verify file permissions: `ls -la data/`
3. Test API endpoint: `curl -X POST yoursite.com/api/visitor-logger.php`

#### Dashboard Not Loading
1. Check API responses in browser developer tools
2. Verify PHP is working: `php -v`
3. Check `.htaccess` configuration

#### Blacklist Not Working
1. Run blacklist processor: `python3 process_w_blacklists.py`
2. Check generated files in `assets/security/`
3. Verify API can read blacklist files

### Debug Mode
Enable debug logging:
```javascript
window.xxmxliTracker = new VisitorTracker({
    debug: true,
    logToConsole: true
});
```
