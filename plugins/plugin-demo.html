🔍 XXMXLI Visitor Tracker Plugin

✨ Features

  • Real-time visitor tracking with IP detection
  • Browser fingerprinting and threat assessment
  • Automatic geolocation and ISP detection
  • Local storage fallback (works without servers!)
  • Built-in admin dashboard (Ctrl+Shift+V)
  • Export/import data functionality
  • Cyberpunk-themed UI
  • Zero dependencies - just one file!

🚀 Quick Start

Add this single line to any website:

<script src="visitor-tracker-plugin.js"></script>

Or with custom options:

<script src="visitor-tracker-plugin.js" data-enable-notifications="true" data-max-stored-visits="200" data-theme="cyberpunk"></script>
