# XXMXLI Incident Reporter - One-Click Installation Guide

## For Non-Technical Users - Simple Setup Instructions

### 🐧 Linux/Unix Users (Ubuntu, Debian, CentOS, etc.)

1. **Download the installer:**
   - Go to the security page on XXMXLI website
   - Click "One-Click Install" button for Linux/Unix
   - Save `install_incident_reporter.sh` to your Downloads folder

2. **Run the installer:**
   - Open Terminal
   - Type: `cd Downloads`
   - Type: `chmod +x install_incident_reporter.sh`
   - Type: `./install_incident_reporter.sh`
   - Enter your password when prompted (for sudo access)

3. **That's it!** The system will:
   - Automatically install all needed software
   - Create all required directories
   - Set up monitoring service
   - Test the system
   - Start protecting your computer immediately

### 🪟 Windows Users

1. **Download the installer:**
   - Go to the security page on XXMXLI website
   - Click "One-Click Install" button for Windows
   - Save `install_incident_reporter.bat` to your Downloads folder

2. **Run the installer:**
   - Right-click on `install_incident_reporter.bat`
   - Select "Run as administrator"
   - Click "Yes" when Windows asks for permission

3. **That's it!** The system will:
   - Automatically configure PowerShell
   - Create all needed folders
   - Install desktop shortcuts
   - Test the system
   - Start monitoring immediately
