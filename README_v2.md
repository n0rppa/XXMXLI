## 🎯 **Quick Start**

### **Option 1: Ultimate Launcher (Recommended)**
```bash
git clone https://github.com/n0rppa/XXMXLI.git
cd XXMXLI
./launch
```

### **Option 2: Individual Enhanced Scripts**
```bash
# Security monitoring with beautiful UI
./monitor_security.sh

# Health check with comprehensive analysis
./health-check.sh

# IP deployment with interactive menus
./deploy_ip_blocking.sh
```

### **Option 3: Command Line (Still Available)**
```bash
# Quick operations
./monitor_security.sh --status
./health-check.sh --full
./deploy_ip_blocking.sh --deploy
```

## 🔧 **Technical Specifications**

- Linux/Unix system (bash shell)
- Python 3.6+ (for launcher)
- Standard Unix utilities (curl, jq, grep, etc.)
